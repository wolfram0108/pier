# pier

Веб-панель управления подключениями для роутера на OpenWrt. Работает поверх ядра
[sing-box-extended](https://github.com/shtorm-7/sing-box-extended) и уживается с
внешним механизмом маршрутизации вроде
[keen-pbr](https://github.com/maksimkurb/keen-pbr): панель отвечает за ноды и
выходной интерфейс, маршрутизатор — за то, какой трафик туда направить.

Поддерживаемые протоколы: vless · vmess · trojan · shadowsocks · hysteria2 ·
tuic · anytls · **mieru** · **naive**.

> **Состояние: переписывается заново.** Первая итерация признана негодной и
> удалена целиком; идёт вторая, по полному техническому заданию. Работающего
> релиза сейчас нет.

## Сборка

Программа собирается одной командой — второго языка сборки в проекте нет:

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath \
  -ldflags "-s -w -X main.version=$(git describe --tags --always)" \
  -o build/pier-arm64 ./cmd/pier
```

Пакет для роутера собирается отдельным скриптом:

```sh
packaging/make-ipk.sh aarch64_cortex-a53 0.2.0 build/pier-arm64
```

Установка на роутер:

```sh
opkg install pier_0.2.0_aarch64_cortex-a53.ipk
```

Служба включается и стартует сама. Данные лежат в `/etc/pier` и переживают
обновление и удаление пакета: этот каталог панели не принадлежит.

## Устройство

Слои и правило зависимостей — `doc/КАРТА.md`. Правило проверяется тестом:

```sh
go test ./internal/arch/
```

Требования к системе живут отдельно от кода, в техническом задании проекта.
Здесь их нет намеренно: код не место для требований, они расходятся.
